Step 1 - Page Selection

The page selected for this assignment is the Master of Science in Criminal Justice webpage.

I selected this page because I am interested in gaining insight into a field closely related to my full-time job.

As someone who works in a police station, I recognize that there is only so much knowledge that can be acquired through on-the-job experience. In many cases, practices can become diluted over time as informal interpretations of policies and procedures are passed from one employee to another.

A formal education in criminal justice can provide a more structured understanding of the field and enhance one's ability to contribute effectively to law enforcement, advocacy, and other areas within the criminal justice system.

According to the assignment criteria, the webpage contains all required structural elements, including a header, footer, navigation area, main content area, lists, and multiple heading levels.

Step 2 - Section-by-Section Layout Analysis

Site Header

The site header contains the Wayne State University name, login directory, search bar, navigation links, and department branding.

I would identify this section using the <header> element because it contains introductory information, navigation, and search functionality.

Main Navigation

The navigation menu appears on the left side of the page and directs users to undergraduate, graduate, and career outlook information.

This section would be marked with the <nav> element because its purpose is navigation.

  • Undergraduate
  • Graduate
    • Master of Science
    • Master of Science and J.D.
    • Chief Scholar's Program
  • Career Outlook

Primary Content

The primary content begins with "Graduate Programs" and concludes with the Forms and Resources sections.

This content would be marked using the <main> element because it contains the primary information users are seeking.

Page Footer

The footer contains contact information, faculty directories, social media links, university policies, and copyright information.

This section would be marked using the <footer> element because it provides supplementary information about the organization.

Step 7 - Accessibility Analysis

The webpage received a score of 9.8 out of 10 in the Web Accessibility Evaluation Tool (WAVE).

No accessibility errors were reported, though seven alerts were identified, including PDF links and the presence of <noscript> elements.

Step 8 - HTML Validation

HTML validation returned two errors and four informational alerts.

One notable error involved an incorrect closing tag in the footer where an <h3> element was closed with </h2>.

Step 9 - HTML Summary

Overall, I found the Master of Science in Criminal Justice webpage to be well-structured and easy to navigate.

The page makes effective use of semantic sections such as the header, navigation menus, main content area, and footer.

The most significant structural issue was the inconsistent heading hierarchy, particularly the absence of H3 headings within the main content despite the visual presentation suggesting a clear hierarchy.

This issue could create confusion for screen reader users who rely on heading structures to navigate content.

The most beneficial improvement would be implementing a more accurate and consistent heading structure throughout the page to improve accessibility and semantic organization.
